# YOLO-SR

This is the open-source code for the paper "A Zero-Cost Super-Resolution and Edge-Aware Architecture for Micro-Scale UAV Object Detection." The paper is currently under review. 
<br>
Abstract : The operational efficacy of Unmanned Aerial Vehicle (UAV) surveillance is constrained by the prevalence of tiny objects, which suffer irreversible feature vanishing during deep convolutional downsampling. Existing lightweight detectors also face a rigid trade-off between localisation precision and the low computational complexity required for real-time edge deployment. To bridge this gap, this paper proposes YOLO-SR, an edge-aware dual-path detection framework built upon the YOLO26n architecture. YOLO-SR rests on a single principle: every component that recovers fine spatial detail operates only during training and is structurally removed before deployment, so that the deployed model matches the baseline in parameter count, FLOPs, and measured inference cost. This principle is instantiated by a Super-Resolution Auxiliary Branch and a Reparameterised Contextual Fusion module that compel the shared backbone to reconstruct high-fidelity spatial details from low-resolution feature maps. A Structure-Aware Multi-Task Loss, combining an Edge-Aware Loss and a Frequency-Domain Consistency Loss under a Detection-Aware Spatial Weighting mechanism, concentrates gradient pressure on sub-resolution objects. Crucially, the auxiliary branch is pruned and the fusion module is merged via closed-form re-parameterisation prior to deployment, ensuring zero inference-time overhead. Compared to baseline YOLO26n, YOLO-SR achieves gains of +3.7% mAP50 on VisDrone2019 (reaching 48.5%), +6.6% on TinyPerson (35.1%), and +2.6% on HazyDet (71.4%), while strictly maintaining the baseline footprint of 2.57 million parameters and 7.8 GFLOPs. Physical deployment on a Huawei Atlas 200 DK edge board sustains 142.9 frames per second with a peak memory footprint of only 74.6 MB. YOLO-SR thus establishes an effective equilibrium between tiny object detection fidelity and stringent edge-computing constraints.
